# 論文整稿室

線上使用：https://profchwu.github.io/thesis/

上傳 Word 論文及學校格式要求，先查看預計修改的條列清單，再確認產生 Word 與修改說明。

## 使用流程

1. 上傳未加密的 `.docx` 論文（最大 30 MB）。
2. 上傳文字型 PDF、Word 或 UTF-8 TXT 格式規範（最大 15 MB），或選取內建清大規範及此瀏覽器記住的規範。
3. 檢視擷取的格式設定，確認正文起始段落。
4. 點選「先列出預計修改項目」，分別查看預計修改、修改位置與待確認事項。
5. 確認後下載 Word 及條列式修改說明。

## 資料與功能範圍

- 不需要 AI API Key，沒有呼叫生成式 AI；採用明確的文字规则擷取及 Word 文件格式處理。
- 論文在瀏覽器記憶體內處理，不上傳 GitHub 或其他伺服器。
- 規範原文存於目前網站的瀏覽器儲存空間，不跨裝置或網址同步；清除網站資料會移除。
- 支援紙張、邊界、字型、字級、行距、黑色文字及頁尾置中設定。
- 保留原文、圖片、公式資料，以及標題、表格、圖說等特殊段落的文字格式。
- 不能保證辨識任意學校的全部規範；不明確項目請對照規範自行指定。掃描 PDF 需先 OCR。
- 封面、簽章文件、引用格式、章節顺序與印刷要求需人工確認；開啟 Word 後更新目錄、頁碼並檢查實際分頁及圖表。字型需安裝在使用者電腦上。

## 發布與開發

本儲存庫為可直接部署的靜態網站，入口是根目錄的 `index.html`，依賴位於 `vendor/`，不需要建置或後端。

GitHub Pages 設定：`main` 分支、`/ (root)` 目錄。推送更新後由 GitHub 自動部署。

本機預覽請以靜態 HTTP 伺服器服務儲存庫根目錄；不要直接以 `file://` 開啟，因為模組及 PDF worker 需要 HTTP/HTTPS。
