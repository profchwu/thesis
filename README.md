# 論文整稿室

線上使用：https://profchwu.github.io/thesis/

上傳 Word 論文及學校格式要求，先查看預計修改的條列清單，再確認產生 Word 與修改說明。

## 使用流程

1. 上傳未加密的 `.docx` 論文（最大 30 MB）。
2. 上傳文字型 PDF、Word 或 UTF-8 TXT 格式規範（最大 15 MB），或選取內建清大規範及此瀏覽器記住的規範。
3. 檢視擷取的格式設定，確認正文起始段落。
4. 點選「先列出預計修改項目」，分別查看預計修改、修改位置與待確認事項。
5. 確認後下載 Word 及條列式修改說明。

## 資料與功能範圍

- 一般排版不需要 API Key，採用文字規則擷取及 Word 文件格式處理。
- 可選用 AI 進階分析：需自行輸入 OpenAI API Key，預設模型為 `gpt-4.1-mini`，可改用支援 Responses 結構化輸出的模型。
- 一般排版在瀏覽器記憶體內處理，不上傳論文。AI 啟用並同意傳送後，所選模組需要的規範、論文文字、書目及查詢結果會送到 OpenAI；DOI 或書目文字會送到 Crossref。API 使用可能產生費用。
- 金鑰只供本次分析使用，不寫入 GitHub、localStorage、sessionStorage 或報告；開始分析後清空輸入框、結束後釋放金鑰變數。瀏覽器 BYOK 仍需信任網站程式與瀏覽器環境；請勿放入開發者共用金鑰。
- 規範原文存於目前網站的瀏覽器儲存空間，不跨裝置或網址同步；清除網站資料會移除。
- 支援紙張、邊界、字型、字級、行距、黑色文字及頁尾置中設定。
- 保留原文、圖片、公式資料，以及標題、表格、圖說等特殊段落的文字格式。
- 不能保證辨識任意學校的全部規範；不明確項目請對照規範自行指定。掃描 PDF 需先 OCR。
- 封面、簽章文件、引用格式、章節顺序與印刷要求需人工確認；開啟 Word 後更新目錄、頁碼並檢查實際分頁及圖表。字型需安裝在使用者電腦上。

## AI 進階分析

1. 匯入論文與規範後，點右上角「AI 進階分析」，勾選啟用並輸入自己的金鑰。
2. 選擇格式規範、参考文獻格式、引用查證、統計檢查等模組。
3. 可複選 APA 7、Harvard（Cite Them Right）、IEEE、MLA 9、Chicago author-date；Word 修訂只使用一種目標格式。
4. 確認參考文獻標題段落，閱讀資料傳送與費用说明，再開始分析。
5. 檢核結果逐項分頁顯示；格式建議與書目修訂分開檢視。逐筆勾選書目後下載修訂 Word；規範建議須回工作台預覽後確認套用。
6. 下載完整 HTML 與 PDF 報告，包含證據、建議、查證來源與時間、覆蓋範圍、部分失敗及限制。PDF 由 HTML 分頁轉成圖像以保留中文字型；要搜尋或複製文字請使用 HTML。

Crossref 登錄存在不代表引用主張正確；查無資料不能判定文獻虛假。未取得全文時只能標示待確認。統計檢查提供文中數值的合理性核對，以及可辨識 t/F/卡方檢定的 p 值重算，不取代原始資料分析。參考文獻以一段一筆處理，APA 7 可選擇同時套用 1.27 公分懸掛縮排與雙倍行距；不自動調整文內編號或文獻排序；特殊欄位段落會阻止自動修訂。

單次上限：論文 30 萬字元、規範 6 萬字元、200 個書目段落；較長內容請分章分析。錯誤或取消時仍可下載已完成部分的報告。

實作與驗證紀錄見 [AI 功能說明](docs/AI.md)。

## 發布與開發

本儲存庫為可直接部署的靜態網站，入口是根目錄的 `index.html`，依賴位於 `vendor/`，不需要建置或後端。

GitHub Pages 設定：`main` 分支、`/ (root)` 目錄。推送更新後由 GitHub 自動部署。

本機預覽請以靜態 HTTP 伺服器服務儲存庫根目錄；不要直接以 `file://` 開啟，因為模組及 PDF worker 需要 HTTP/HTTPS。

## 第三方套件

使用 JSZip、Mozilla PDF.js、html2canvas 1.4.1、pdf-lib 1.17.1 與 jStat 1.9.6。第三方著作權及授權聲明保留於各原始套件檔案；其授權依各套件聲明。
